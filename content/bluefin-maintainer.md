### What is a Bluefin??
Bluefin is a Bootc based Linux supposed to kill the product of Linux Distros, the reason why is because we should just have what the cloud does which is just a good provider of software not a "distro" of a kernel, it should mainly be containers that don't vendor-lock you into anything.

### What is a Bootc?
Bootc stands for Bootable Container the main overview as they put it is "Transactional, in-place operating system updates using OCI/Docker container images." now why is this better? The Reason for this being a better way to Linux is because the step of building your OS is instead of run time it's build time so you can catch errors easily and have everything in git!
